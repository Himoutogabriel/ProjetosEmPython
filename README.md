# Projetos em Python

Repositório criado para registrar minha evolução no aprendizado de Python, reunindo exercícios, práticas, experimentos e projetos desenvolvidos durante minha formação em Engenharia de Computação.

A ideia é utilizar este repositório não apenas para armazenar códigos, mas também para acompanhar minha evolução à medida que novos conceitos são estudados e aplicados em projetos práticos.

## Sobre

Este repositório reúne projetos desenvolvidos durante meus estudos de Python, começando pelos fundamentos da linguagem e avançando gradualmente para conceitos de Programação Orientada a Objetos, manipulação de dados, integração com banco de dados e desenvolvimento de aplicações.

Os projetos são desenvolvidos principalmente com o objetivo de aprender na prática, testar conceitos e transformar conhecimentos teóricos em código.

## Conteúdos estudados

Ao longo do repositório são trabalhados conceitos como:

* Fundamentos de Python
* Variáveis e tipos de dados
* Estruturas condicionais
* Laços de repetição
* Funções
* Listas, tuplas e dicionários
* Programação Orientada a Objetos (POO)
* Classes, objetos e métodos
* Manipulação de dados
* Integração com PostgreSQL
* Operações CRUD
* Tratamento de exceções
* Testes e experimentação
* Lógica de programação

## Projetos

### Sistema Bancário

Projeto desenvolvido para praticar conceitos de Programação Orientada a Objetos.

Durante o desenvolvimento foram trabalhados conceitos como:

* Classes e objetos
* Herança
* Encapsulamento
* Métodos
* Organização de entidades
* Manipulação de contas e clientes

### Sistema de Despensa

Aplicação de linha de comando desenvolvida para praticar a integração entre Python e PostgreSQL.

O sistema permite:

* Adicionar produtos
* Buscar produtos pelo código
* Listar produtos
* Remover produtos
* Atualizar informações
* Persistir os dados em PostgreSQL

Tecnologias e conceitos utilizados:

* Python
* Programação Orientada a Objetos
* PostgreSQL
* psycopg2
* SQL
* CRUD
* Estruturas de dados

Este projeto representa uma etapa importante da minha evolução, pois une conceitos de Python e POO com persistência de dados em um banco de dados relacional.
