# Projetos em Python

Repositório destinado ao armazenamento de projetos, exercícios e práticas desenvolvidos durante meus estudos da linguagem Python.

## Sobre o repositório

Os conteúdos deste repositório acompanham minha evolução no aprendizado de Python, desde os fundamentos da linguagem até conceitos de programação orientada a objetos e desenvolvimento de pequenos projetos.

## Conteúdos estudados

* Variáveis e tipos de dados
* Estruturas condicionais
* Laços de repetição
* Funções
* Listas e outras estruturas de dados
* Programação Orientada a Objetos (POO)
* Classes e objetos
* Organização e desenvolvimento de projetos
* Lógica de programação

## Organização

O repositório está dividido em diretórios de acordo com os conteúdos estudados:

* `condicionais` — práticas com `if`, `elif` e `else`
* `laços` — exercícios utilizando estruturas `for` e `while`
* `funções` — criação e utilização de funções
* `poo` — estudos de Programação Orientada a Objetos
* `projetos` — pequenos projetos desenvolvidos durante os estudos
* `ideias` — experimentos e ideias em desenvolvimento

## Objetivo

Este repositório serve como registro da minha evolução em Python e como espaço para colocar em prática os conceitos estudados durante minha formação em Engenharia de Computação e em cursos complementares.

O conteúdo continuará sendo atualizado conforme avanço nos estudos e desenvolvo novos projetos.
